# results/

Everything the system produces. Four subfolders:

| Folder | Contains | Made by | In Git? |
|---|---|---|---|
| `logs/` | One row per question: the raw record of every run | `python -m src.pipeline` | No: regenerated by running |
| `tables/` | Summary tables for the latest run | `python -m src.evaluate` | No |
| `plots/` | Charts drawn from a hand-built threshold sweep | `evaluate.plot_tradeoff()` | No |
| `analysis/` | Saved outputs of the research scripts that chose the router | `scripts/probe_reward_model.py`, `scripts/train_router.py` | Yes, except the large cache file |

The logs are the ground truth: if a number on the dashboard or in a table looks wrong, check it here. See `logs/README.md` for
every column, and the README in each other folder for its files.
