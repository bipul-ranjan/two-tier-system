# results/

Everything generated by running the pipeline lives under here, split
into three stages of the same data:

| Subfolder | Contains | Generated by |
|---|---|---|
| `logs/` | Raw, per-query records — one row per query processed | `python -m src.pipeline` |
| `tables/` | Aggregated metrics computed from the logs | `python -m src.evaluate` |
| `plots/` | Chart images built from a manual threshold sweep | `evaluate.plot_tradeoff()` |

See the README inside each subfolder for exact file names and column
definitions. None of this is tracked by Git — it's all reproducible by
re-running the pipeline, so there's nothing here worth
version-controlling directly.
